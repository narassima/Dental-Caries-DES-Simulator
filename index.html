Mathematical Formulation & Simulation Mechanics

Faithfully reproduces the discrete event simulation logic detailed in the manuscript and Annexure A.

1. Camp Queuing Logic (Lindley Recursion)

Each camp is an 8-hour shift (480 minutes). Students arrive as a batch of size N ~ Ceil(U(8,12)) × (1 + TS%). The auxiliary admits each student in FIFO order:

A_done[j] = ∑ adm[k],   with adm ~ Uniform(0.5, 1.5) minutes

For any server r ∈ {dentist, auxiliary, teacher}, student j starts service at:

Start[j] = max(Ready[j], Free_Time[r]),   Served if Start[j] < 480 min

2. 10-Month School-Year Layer & Pool Depletion

In months t = 2...10, repeat visits consume a share ρ (base 15%):

Rep[g] = min(ρ × S[g], U[g]),   New[g] = min(S[g] - Rep[g], P[g] - U[g])

3. Health Outcomes: Years Lived with Disability (YLDs)

YLD_dur = ∑ Eff_New[g, i] × DW[i] × [ (1 - e^(-0.03 × dur[i])) / 0.03 ]

4. Dedicated School Workforce Gap

Dedicated_Dentists_Needed = Unmet_Need / 1,889

How to Use the Dental Caries DES Platform

Step-by-step interactive manual & system guide
1

Understanding the Core Simulation Engine

This application simulates school-based dental camps using Discrete Event Simulation (DES) with the Lindley recursion. Unlike static spreadsheets, it explicitly models individual student queues, stochastic arrival batches, auxiliary triage, procedure durations, and a strict 480-minute (8-hour) daily shift cut-off.

2

Exploring the 4 Feasibility Tiers (Executive Dashboard)

On the Executive Dashboard, click between the 4 feasibility tiers: Status Quo (2 camps/mo, TS 0%), Plausible (8 camps/mo, TS 30% — headline target), Stretch (12 camps/mo, TS 30%, φ=0.8), and Theoretical Max (22 camps/mo, φ=1.0). Observe how coverage, unmet need, and dentist utilization update immediately.

3

Interactive Camp Simulation with Animation & Speed Controls

Go to Camp DES & Timeline and click Start Animation. Use the speed controls (0.5x, 1x, 2x, 5x) to watch the digital camp clock advance from 09:00 AM to 05:00 PM. Watch students arrive, undergo auxiliary admission, get triaged, and receive treatment across separate non-overlapping tracks for Dentist, Auxiliary Admissions, Auxiliary Fluoride, and Teacher.

4

Viewing All 9 Manuscript Plots (Manuscript Plots Tab)

Visit the Manuscript Plots (Fig 1–9) tab to view interactive Chart.js reproductions of all 9 figures from the paper, including Resource Utilization (Fig 2), Feasibility Tiers (Fig 3), Age-Specific Reach (Fig 4), DMFT Reduction (Fig 5), State Rankings (Fig 6), Structural Disparities (Fig 7), Scenario Heatmaps (Fig 8), and PSA Tornado (Fig 9).

5

Configuring Monte Carlo PSA Draws (Max Cap 200)

In the Scenario Grid & PSA tab, select the number of Monte Carlo draws using the number input, slider, or quick chips (25, 50, 100, 200). The simulation enforces a maximum cap of 200 draws for responsive in-browser performance.

6

Using the 'i' Field Information Buttons

Click any circular i button next to any KPI, parameter slider, or table header to view its clinical definition, mathematical formula, baseline benchmark, and paper citation.
